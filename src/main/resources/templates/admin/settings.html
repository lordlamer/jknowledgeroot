Two-factor authentication

Users set up an authenticator app in their profile. The policy decides who is asked for a code and who must set one up at the next sign-in.

MCP server for AI assistants

Assistants such as Claude connect to https://example.org/mcp, sign in as the user with the normal login and then read or, if allowed on the consent page, write with that user's permissions. See docs/mcp.md. Connections and the audit log are under Admin → MCP.

Hosts an assistant may name as return address when it registers, one per line; *.example.org covers sub-domains. Assistants on the user's own machine (localhost) are always allowed.

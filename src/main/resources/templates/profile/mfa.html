Two-factor authentication

A code from an authenticator app in addition to your password.

Two-factor authentication removed.

Two-factor authentication is switched off for this installation. A token you set up now is kept and used once an administrator enables it.

Your account must use a second factor.

Not set up

Set up an authenticator app such as Microsoft Authenticator, Google Authenticator or 1Password. You will get ten recovery codes for the case that you lose the app.

Active

Set up on date. Unused recovery codes: 10.

No recovery codes left. Remove and set up the second factor again to get new ones.

Remove

Removing needs your password and a current code. Afterwards you sign in with the password only, unless the policy requires a token.

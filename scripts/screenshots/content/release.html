Cadence

We release every two weeks on Tuesday. Hotfixes go out as needed from the maintenance branch.

Checklist

  1. Changelog reviewed, version bumped
  2. Tag pushed; CI verifies and publishes the images and the checksums
  3. Staging upgraded from the published image, smoke test green
  4. Production upgraded during the maintenance window
  5. Announcement in the release channel

Rollback

Roll back by deploying the previous image. Database migrations are backward compatible for one release; see the runbook Database backup and restore.

git tag v1.4.0
git push origin v1.4.0

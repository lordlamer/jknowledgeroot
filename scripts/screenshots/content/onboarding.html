Before day one

  • Laptop ordered and enrolled
  • Accounts: Git hosting, chat, knowledge base, ticket system
  • Buddy assigned for the first two weeks

First week

  1. Clone the main repositories and run the build locally
  2. Read the Code review guidelines and the last five merged pull requests
  3. Pair with your buddy on one small ticket
  4. Ship something: a documentation fix counts

First month

  • Shadow one on-call shift
  • Present one architecture decision in the team meeting

Nightly backup

A cron job on the database host dumps the schema and data at 02:00 and uploads the compressed dump to the backup bucket. Retention is 30 days.

mariadb-dump --single-transaction --routines knowledgeroot | zstd -19 > knowledgeroot-$(date +%F).sql.zst

Verify

  • The dump is not more than 10 % smaller than the previous one
  • A restore into the throwaway database succeeds and the row counts match

Restore

  1. Stop the application
  2. Restore the dump into a fresh database
  3. Start the application; migrations run on start
  4. Check the readiness endpoint and sign in
